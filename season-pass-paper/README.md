# SeasonPass (Paper plugin)

A free, cosmetic-only battle pass. Any kind of play earns pass XP: hostile kills +5, mining +1 (capped 200/day), fishing +10, advancements +25, playtime +2/min.

- 20 tiers (tier N needs N×100 more XP). Rewards alternate: 5 chat name colors, 5 particle trails, 10 escalating titles ([Wanderer] → [Mythic]).
- `/pass` opens the track GUI — click unlocked rewards to equip/unequip (one color, one trail, one title at a time).
- Titles and name colors show in chat and the tab list; trails follow you as you move.

Install: drop the jar in `plugins/`, restart. Paper/Purpur 1.21.4+ (uses Paper's chat renderer), Java 21.
