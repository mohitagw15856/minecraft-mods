# MobMoods (Paper plugin)

Zombies, skeletons, creepers and spiders spawn with a mood — 25% cheerful, 50% neutral, 25% grumpy.

- Cheerful creepers never explode. Cheerful skeletons hold fire half the time (musical notes instead).
- Grumpy zombies/spiders get Speed I; all grumpy mobs hit +1 damage harder.
- Moods are visible: green sparkles = cheerful, smoke = grumpy.
- Right-click a moody mob with sweet berries to shift it one step toward cheerful.
- `/moods` — how it works + live counts. `/moods on|off` — (op) toggle the system.

Install: drop the jar in `plugins/`, restart. Paper/Spigot/Purpur 1.21.4+, Java 21.
