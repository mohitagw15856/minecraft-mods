# SwornRivals (Paper plugin)

Every 7 in-game days the server secretly pairs players as rivals. Outscore yours to steal the Rival's Edge (Speed I + 10% bonus points for the whole next week).

- Scoring: hostile mob kill +1, ore mined +2, player kill +5.
- `/rivals` — your rival, the score duel, lifetime wins.
- `/rivals shuffle` — (op) reshuffle pairs immediately.
- Week rollover settles every pair, broadcasts the top 3 scorers, and re-pairs online players.

Install: drop the jar in `plugins/`, restart. Paper/Spigot/Purpur 1.21.4+, Java 21.
